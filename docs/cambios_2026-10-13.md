# Biblioteca Córdoba — cambios 13/10/2026

## Formulario de libros
- El campo de fecha de publicación ahora se muestra como control de fecha visible y permite escribir una fecha o usar el calendario del navegador.
- Al validar el formulario, el año de la fecha elegida se copia al campo `anio` del modelo.
- El año numérico tiene límite visual de cuatro caracteres y un rango de validación.

## Comprobante del lector
- Se cambiaron las etiquetas `OBRA` y `AUTORÍA` por `NOMBRE DEL LIBRO` y `AUTOR`.

## Pruebas pendientes
Este paquete no debe considerarse validado hasta ejecutar las pruebas de Django localmente. Probar crear y editar libros cambiando el año tanto escribiendo la fecha como eligiéndola con el calendario.
